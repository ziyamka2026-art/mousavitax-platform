# بازار مشاوران سراسری

## هدف
ثبت‌نام مشاوران مالیاتی در **کل کشور**، پروفایل عمومی، درخواست مشاوره، و اتصال به AI.

## قابلیت‌های هدف

| قابلیت | توضیح |
|--------|--------|
| ثبت‌نام مشاور | احراز هویت، تخصص، استان/شهر، مدارک حرفه‌ای |
| پروفایل عمومی | امتیاز، حوزه‌ها، وضعیت آنلاین، تعرفه |
| فیلتر جغرافیایی | استان، شهر، حضوری/آنلاین |
| درخواست مشاوره | تلفنی، متنی، حضوری |
| ارجاع از AI | وقتی APCS وضعیت `HUMAN_REVIEW_REQUIRED` می‌دهد |

## مدل داده پیشنهادی (خلاصه)
- `Advisor`: user_id, provinces[], specialties[], license_ref, status
- `ConsultationRequest`: client_id, advisor_id, channel, status
- `Review`: rating, comment

## مسیرهای آینده در API
- `POST /v1/advisors/register`
- `GET /v1/advisors?province=&specialty=`
- `POST /v1/consultations`

## پنل‌ها
- وب: `/advisors` (اسکلت موجود)
- `apps/admin`: تأیید مدارک مشاور

## به‌روزرسانی
- **انسان:** سیاست تأیید مدارک، تعرفه‌ها، شکایات
- **AI:** پیشنهاد مشاور بر اساس موضوع سؤال و استان کاربر
