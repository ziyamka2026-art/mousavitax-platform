# کانال‌های پیام‌رسان — تلگرام و بله

## هدف
دسترسی سراسری کاربران ایرانی از طریق پیام‌رسان‌های رایج، با یک Backend واحد.

## معماری

```
کاربر تلگرام ──► apps/telegram-bot ──┐
                                    ├──► apps/api (Gateway + APCS + RAG)
کاربر بله    ──► apps/bale-bot ─────┘
```

| کانال | مسیر | وضعیت |
|--------|------|--------|
| Telegram | `apps/telegram-bot` | اسکلت آماده |
| Bale (بله) | `apps/bale-bot` | اسکلت برنامه‌ریزی‌شده |

## قواعد مشترک
1. ربات‌ها **thin adapter** هستند؛ بدون منطق مالیاتی محلی.
2. Citation و disclaimer در پاسخ نمایش داده شود.
3. انتقال به مشاور انسانی از طریق لینک/دکمه به وب یا درخواست در پنل.
4. توکن‌ها فقط در `.env` / secret store.

## به‌روزرسانی
- **انسان:** توکن، متن welcome/help، moderation
- **AI/توسعه:** همگام‌سازی قرارداد API با Gateway؛ افزودن دکمه «درخواست مشاور»
