# Benchmark نما و جهت‌گیری محصول MousaviTax AI

**منبع:** گزارش تکمیلی نسخه ۱ (بررسی محصول/کسب‌وکار moshaver.namatsp.ir)  
**قاعده:** محتوای حقوقی/مالیاتی رقیب فقط Benchmark است و **وارد Knowledge Base نمی‌شود** مگر از منابع رسمی اعتبارسنجی‌شده.

## ۱. نتیجه کلیدی

MousaviTax AI نباید فقط «چت‌بات مالیاتی» باشد. هدف:

> **AI-Native Tax Platform** = Service-Based + Case-Based + Triage + RAG با Citation + Human-in-the-loop

نه کپی Marketplace نما.

## ۲. مدل Hybrid (قابل اتکا)

```
مسئله کاربر
  → AI Tax Triage
      → ساده: پاسخ AI + Citation
      → متوسط: AI + Quality Gate / کنترل
      → پیچیده: ارجاع مشاور متخصص (+ تحلیل AI اختیاری)
  → خروجی نهایی می‌تواند AI + تأیید متخصص باشد
```

## ۴. مدل درآمدی پیشنهادی

| سطح | محتوا |
|-----|--------|
| ۱ رایگان | پاسخ اولیه AI + Citation محدود |
| ۲ AI Premium | تحلیل مستند + استناد گسترده‌تر |
| ۳ AI + Expert | بررسی مشاور روی خروجی AI |
| ۴ پرونده تخصصی | اسناد، استراتژی دفاع، لایحه، نظارت |

## ۵. مسیر کاربر هدف

ثبت مسئله → تشکیل **Tax Case** → بارگذاری مدارک → تحلیل AI → منابع قانونی → ارزیابی ریسک → انتخاب مشاور (در صورت نیاز) → لایحه/راهکار → پیگیری مهلت‌ها → آرشیو → گزارش نهایی.

## ۶. تفاوت راهبردی با نما

| نما (الهام) | MousaviTax AI |
|-------------|---------------|
| واسط مشاور | AI-Native + Human-in-the-loop |
| خدمت دستی‌محور | Tax Case Engine + Document AI + Triage |
| دانش محتوایی سایت | Tax Knowledge از منابع رسمی |
