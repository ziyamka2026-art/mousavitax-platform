# MousaviTax Office Agent

عامل همکاری داخلی برای پلتفرم و دفتر مشاوره موسوی جراحی.

## نقش
- تحلیل وضعیت پرونده‌ها
- شناسایی مهلت‌های نزدیک
- پیشنهاد وظایف
- تولید خلاصه مدیریتی

## اصول امنیتی
1. دسترسی مستقیم به پایگاه داده ممنوع است.
2. همه عملیات از طریق Service/API مجاز انجام می‌شود.
3. مالکیت پرونده و سطح دسترسی باید توسط سرویس مقصد بررسی شود.
4. نسخه اول فقط Read + Suggest است.
5. پاسخ تخصصی مالیاتی بدون Evidence معتبر نباید قطعی تولید شود.

## نام‌گذاری نقش‌ها
از اصطلاح «کارمند اداره مالیات» استفاده نمی‌شود. نقش‌های داخلی شامل «کارمند پلتفرم» و «کارمند دفتر مشاوره موسوی جراحی» هستند.
